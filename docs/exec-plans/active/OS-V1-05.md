## Design decisions and why

- **"Support access... audited" is satisfied structurally, not by a new primitive.** Any staff principal who actually EXERCISES a delegated or ordinary grant to perform a protected action must go through `authorizeProtectedDecisionResume`, whose own return type (`ProtectedDecisionResumeAuthorization`) makes `decisionEvidenceRef` and `resolvedAt` mandatory, non-optional fields — there is no code path that produces a resume authorization without a durable evidence reference and timestamp. W2 asserts this directly (`resumeAuthorization.decisionEvidenceRef.length > 0`). A dedicated "break-glass"/support-specific audit ledger is explicitly AA-005 REV209's own separate OS-V1-09 ("Observability / Support / Break-Glass") concern, not this task's — inventing one here would be scope creep into a not-yet-selected later package.
- **The end-to-end composition (W2) deliberately keeps protected-action authority with the delegator, never the delegate**, demonstrating "approval never becomes execution authority" at the SYSTEM level, not just the function level: the delegate's own grant explicitly sets `canPerformProtectedActions: false`, so even though the delegate can raise a protected-decision wait (raising is never itself authority-gated — fail-closed-by-pausing is always safe), only the OWNER (who retains full authority, never having delegated it away) can actually approve+resume. This proves the "approval/execution separation" survives composition with delegation, not merely in isolation.
- **W6 (human/worker substitution inside delegation)** is the one genuinely new adversarial path: OS-V1-02's own Rev208 I/J witnesses proved a worker object cannot satisfy `resolveEffectiveOrganizationAccess`'s/`resolveEffectiveServicePrincipalAccess`'s own structural type slots, but never specifically that a worker's `workerRef` string cannot be asserted as a human delegate's `currentPrincipalRef` inside `resolveEffectiveDelegatedAccess` — a different call site with its own independent exact-match check. This closes that specific seam.
