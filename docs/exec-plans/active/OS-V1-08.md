## Design decisions and why

- **FAN1 scales the existing 2-way race to 10-way, against the UNIT FLOOR specifically** (not the monetary ceiling P1 already covers) — REV209's own word "fan-out" names a different adversarial shape than "a race": many more concurrent admitters than winners, which stresses the atomic-claim mechanism's correctness under contention the existing 2-way test cannot exercise (a 2-way race can only ever produce one winner and one loser; a 10-way race against a 3-slot ceiling must produce EXACTLY 3 winners and 7 losers — any fourth winner would be a real ceiling breach the 2-way test structurally cannot detect).
- **RETRY1 composes `deriveQuotaReservationIdempotencyKey`'s own real per-attempt identity** (distinct `attemptRef` → distinct idempotency key, exactly how an `OutcomeJob` retry would actually present itself to this admission floor) rather than inventing a synthetic retry concept — proving that minting a fresh idempotency key for a new attempt is never itself a way to acquire quota the SCOPE's cumulative usage has already exhausted.
- **FALLBACK1 deliberately never supplies attribution at admission time** — because `admitQuotaReservation`'s own signature has no attribution parameter at all (attribution is recorded only at `commitQuotaUsage`, i.e. at settlement, never at the gate that actually enforces the ceiling). This is the strongest possible proof that cost/quota admission is "cheaper/faster ineligible route cannot override policy" by construction: a fallback route cannot even present different attribution to the admission gate to try to bypass it, because the gate doesn't take attribution as an input in the first place.

## Required witnesses → coverage

8 new tests in `tests/os-v1-08-cost-quota-concurrency-fairness.test.ts`:

| Witness | Covers |
|---|---|
| RACE1 | Two concurrent admissions together exceeding the limit resolve to exactly one RESERVED, one REJECTED (cited/re-demonstrated) |
| FAN1 | Ten concurrent admissions against a 3-slot unit floor resolve to EXACTLY 3 RESERVED, 7 REJECTED — the fan-out witness |
| SETTLE1 | An identical-content duplicate commit is a safe no-op; a divergent-content duplicate commit throws `QuotaReservationConflictError` — never a silent double settlement (cited/re-demonstrated) |
| RETRY1 | Three sequential retries (distinct `attemptRef`/idempotencyKey) against a 2-slot ceiling: the third is REJECTED by cumulative scope usage, never granted a fresh budget |
| FALLBACK1 | A second attempt against an already-exhausted 1-slot scope is REJECTED regardless of being a "different route" — admission never inspects attribution |
| ATTR1 | `commitQuotaUsage` preserves real worker/provider/model/route attribution exactly, and never fabricates it when absent (cited/re-demonstrated) |
| CROSSORG1 | Two tenants sharing an identical bare `customerId`/`projectId`/`planId` string, admitted against the SAME shared store instance, produce zero cross-consumption of each other's ceiling (cited/re-demonstrated) |
| ENVELOPE1 | A fallback worker candidate missing a required tool/policy/authority constraint is never selected over policy, regardless of cost ordering (cited/re-demonstrated) |
