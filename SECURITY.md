# Security Policy

The English text below is the drafting basis for this policy; the
Turkish text is a materially equivalent translation. Neither version
grants broader rights or omits a restriction present in the other. The
"Contact: TBD" gap described below is identical in both versions — it is
not translated away.

Aşağıdaki İngilizce metin bu politikanın hazırlanış esasıdır; Türkçe
metin buna maddi olarak eşdeğer bir çeviridir. Aşağıda açıklanan
"İletişim: BELİRLENECEK" boşluğu her iki sürümde de aynıdır — çeviriyle
giderilmemiştir.

## English

This repository holds proprietary software owned by 7T Tekstil Sanayi ve
Ticaret Limited Şirketi ("7T"). We take security reports seriously and ask
that they be reported privately rather than through public GitHub issues
or pull requests.

### Reporting a vulnerability

**Contact: TBD**

A verified security contact address for this repository has not yet been
established in the project's records. This is the single open item in
this policy and is called out here deliberately rather than inventing an
address: **do not publish, guess, or use any address not confirmed by the
repository owner.** The owner should fill in a verified contact here
before this policy is treated as complete.

Until a verified contact is set, if you believe you have found a security
vulnerability in this repository, do not disclose it publicly. Instead,
use whatever private channel you already have with 7T's designated
repository owner (see `.github/CODEOWNERS`) to report it.

### Please do not

- open a public GitHub issue describing an unpatched vulnerability;
- publicly disclose a vulnerability before it has been addressed; or
- test for vulnerabilities against any production system without prior
  written authorization.

### What to include

When reporting, please include as much of the following as you can:

- a description of the vulnerability and its potential impact;
- steps to reproduce, or a proof of concept;
- the affected file(s), commit SHA, or version, if known.

## Türkçe

Bu depo, 7T Tekstil Sanayi ve Ticaret Limited Şirketi'ne ("7T") ait
tescilli (proprietary) bir yazılımı barındırmaktadır. Güvenlik
bildirimlerini ciddiye alıyoruz ve bunların herkese açık GitHub issue
veya pull request'ler yerine gizli (private) olarak bildirilmesini rica
ediyoruz.

### Bir Güvenlik Açığını Bildirmek

**İletişim: BELİRLENECEK**

Bu depo için doğrulanmış bir güvenlik iletişim adresi projenin
kayıtlarında henüz oluşturulmamıştır. Bu, bu politikadaki tek açık madde
olup, bir adres uydurmak yerine kasıtlı olarak burada belirtilmektedir:
**depo sahibi tarafından doğrulanmamış hiçbir adresi yayınlamayın,
tahmin etmeyin veya kullanmayın.** Depo sahibi, bu politika tamamlanmış
sayılmadan önce burada doğrulanmış bir iletişim bilgisi girmelidir.

Doğrulanmış bir iletişim bilgisi belirlenene kadar, bu depoda bir
güvenlik açığı bulduğunuzu düşünüyorsanız, bunu herkese açık şekilde
ifşa etmeyin. Bunun yerine, bunu bildirmek için 7T'nin belirlediği depo
sahibi ile zaten sahip olduğunuz herhangi bir özel (private) iletişim
kanalını kullanın (bkz. `.github/CODEOWNERS`).

### Lütfen Yapmayın

- Yamalanmamış bir güvenlik açığını açıklayan herkese açık bir GitHub
  issue açmayın;
- Bir güvenlik açığı giderilmeden önce bunu herkese açık şekilde ifşa
  etmeyin; veya
- Önceden yazılı izin almadan herhangi bir üretim (production) sistemine
  karşı güvenlik açığı testi yapmayın.

### Nelerin Dahil Edilmesi Gerekir

Bildirim yaparken, mümkün olduğunca aşağıdakileri dahil etmenizi rica
ederiz:

- Güvenlik açığının ve olası etkisinin bir açıklaması;
- Yeniden üretme adımları veya bir kavram kanıtı (proof of concept);
- Biliniyorsa, etkilenen dosya(lar), commit SHA'sı veya sürüm bilgisi.
