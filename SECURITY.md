# Security Policy

This repository holds proprietary software owned by 7T Tekstil Sanayi ve
Ticaret Limited Şirketi ("7T"). We take security reports seriously and ask
that they be reported privately rather than through public GitHub issues
or pull requests.

## Reporting a vulnerability

**Contact: TBD**

A verified security contact address for this repository has not yet been
established in the project's records. This is the single open item in
this policy and is called out here deliberately rather than inventing an
address: **do not publish, guess, or use any address not confirmed by the
repository owner.** The owner should fill in a verified contact here
before this policy is treated as complete.

Until a verified contact is set, if you believe you have found a security
vulnerability in this repository, do not disclose it publicly. Instead,
use whatever private channel you already have with 7T's designated
repository owner (see `.github/CODEOWNERS`) to report it.

## Please do not

- open a public GitHub issue describing an unpatched vulnerability;
- publicly disclose a vulnerability before it has been addressed; or
- test for vulnerabilities against any production system without prior
  written authorization.

## What to include

When reporting, please include as much of the following as you can:

- a description of the vulnerability and its potential impact;
- steps to reproduce, or a proof of concept;
- the affected file(s), commit SHA, or version, if known.
