# Contributing

This repository holds proprietary software owned by 7T Tekstil Sanayi ve
Ticaret Limited Şirketi ("7T"). It is not an open-source project, and it
does not operate an open contribution model.

## Unsolicited contributions

7T does not accept unsolicited code, documentation, design, or other
contributions to this repository. If you submit a pull request, issue, or
other content to this repository without prior written authorization from
7T:

- 7T is under no obligation to review, use, merge, or respond to it;
- submitting it does not grant you any ownership, license, or other
  interest in this repository or in 7T's software; and
- it may be closed, ignored, or removed without notice.

## Authorized contributors

Contributions are accepted only from individuals or organizations that
have received prior written authorization from 7T and, where applicable,
have entered into a separate written agreement with 7T governing
ownership and licensing of their contribution (for example, a contributor
agreement or IP-assignment agreement). No such agreement is implied by
this document, and none currently exists as a public or automated
process — authorization is arranged directly with 7T on a case-by-case
basis.

## Reporting issues

If you have found a bug or have a question about this repository, you may
open an issue, but please note that doing so does not create any
contribution or licensing relationship described above. For security
vulnerabilities, see SECURITY.md instead of opening a public issue.
